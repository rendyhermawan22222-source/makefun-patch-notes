One line, 160 characters at most: a software patch note for a bug in real life or human biology, in the terse register of a real release note.

Our line is deadpan machine logic applied to the most human bug there is: you walk into a room and the reason for going there is gone. The bug is a null pointer; the cause is the garbage collector. Version number, terse engineering register, fix stated as if it shipped — and the last two words are the punchline.

## Run it

```sh
python3 main.py
```

Writes the 100-character line to `/output/entry.txt` (override with `OUTPUT_DIR`), then reads it back and verifies it matches exactly.
